# FieldMaps International Administrative Boundaries

Admin level 0 boundaries built from the U.S. Department of State's LSIB boundary lines combined with either State Department World Polygons (CC0) or OpenStreetMap land polygons (ODbL). Each source comes in a humanitarian and a disaggregated view, as GeoParquet polygons, lines and points with PMTiles. Catalog metadata is CC0-1.0; data licenses are set per folder: cc0/ is CC0-1.0, odbl/ is ODbL-1.0.
